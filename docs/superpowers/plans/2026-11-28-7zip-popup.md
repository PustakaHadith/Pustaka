# 7-Zip Popup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tambah pautan "Muat Turun 7-Zip" dalam kad Portable ZIP di `landing-page/mockup-pro.html` yang membuka popup penerangan dengan butang ke laman muat turun rasmi 7-Zip, dalam MS dan EN.

**Architecture:** Satu `<dialog>` asli ditambah pada halaman, dibuka dengan `showModal()` dari pautan tekstual di kad ZIP. Pelayar mengurus Esc, klik latar, dan pemulihan fokus. Teks popup mengikut corak i18n sedia ada: kandungan MS ialah HTML asal dengan `data-i18n`, dan terjemahan EN dimasukkan ke `I18N.en`. Tiada pustaka luar, tiada fail baharu selain dokumen perancangan.

**Tech Stack:** Vanilla HTML / CSS / JavaScript; `<dialog>` API; mekanisme `data-i18n` + `I18N.en` sedia ada.

**Spec:** `docs/superpowers/specs/2026-11-28-7zip-popup-design.md`

## Global Constraints

- "Vanilla HTML/CSS/JS sahaja, selari dengan halaman ini."
- Teks MS ialah kandungan HTML dengan `data-i18n`; `setLang('en')` menggantikan `innerHTML` daripada `I18N.en`.
- "`prefers-reduced-motion` sudah dimatikan secara global oleh media query sedia ada — popup tidak perlu animasi khas."
- "Commit mesti ter-skop: hanya `landing-page/mockup-pro.html` dan/atau `docs/superpowers/`. Tiada `git add -A`, tiada push tanpa kelulusan."
- Butang CTA: `https://www.7-zip.org/download.html`, `target="_blank"`, `rel="noopener"`.
- Kad Microsoft Store dan Setup EXE tidak diubah; pautan muat turun ZIP sedia ada tidak diubah.

## Review Focus

- **RF1** — Klik pautan `#z7-link`: popup terbuka dan `location.href` tidak berubah. Diuji Task 1 Step 2 & Step 4.
- **RF2** — Tutup dengan butang × dan klik latar: dialog tertutup dan fokus kembali ke `#z7-link`. Diuji Task 1 Step 4. Esc dikendali asli oleh pelayar; disahkan secara manual kerana `KeyboardEvent` tiruan automation tidak boleh dipercayai.
- **RF3** — Toggle EN/MS semasa popup terbuka: semua teks popup bertukar (tajuk, penerangan, 3 langkah, CTA, aria tutup) dan kembali MS selepas reload. Diuji Task 2 Step 2 & Step 4.
- **RF4** — Butang CTA dalam popup: `href` tepat laman rasmi, `target="_blank"`, `rel="noopener"`. Diuji Task 1 Step 4.
- **RF5** — Tiada regresi: butang "Muat Turun ZIP" asli masih ada `href`/`download` asal, tiada ralat konsol, dan `prefers-reduced-motion` tidak menimbulkan ralat. Diuji Task 1 Step 4.

- Tambah CSS minimum untuk `dialog::backdrop`, `dialog[open]`, dan pautan; guna `var(--surface)`, `var(--line)`, `var(--txt)`, `var(--brand)` mengikut corak sedia ada. Tiada animasi khas.

- [ ] **Step 4: Sahkan ujian lulus (GREEN) + Review Focus**

Run: `browser.evaluate`:

```js
(()=>{
  const link=document.getElementById('z7-link');
  const dlg=document.getElementById('z7-dialog');
  const before=location.href;
  link.click();
  const opened=dlg.open;
  const cta=document.getElementById('z7-download');
  const zip=document.querySelector('a[href*="PustakaHadith-portable"]');
  const mid=location.href;
  document.getElementById('z7-close').click();
  const closedByButton=!dlg.open;
  const focusRestored=document.activeElement===link;
  link.click();
  dlg.click(); // klik pada permukaan dialog di luar kandungan dalaman
  const closedByBackdrop=!dlg.open;
  return {
    opened, closedByButton, closedByBackdrop,
    noNavigation:before===mid,
    cta:{href:cta.getAttribute('href'),target:cta.getAttribute('target'),rel:cta.getAttribute('rel')},
    zipIntact:!!zip&&zip.hasAttribute('download'),
    focusRestored
  }
})()
```

Assert: `opened===true`, `closedByButton===true`, `closedByBackdrop===true`, `noNavigation===true`, `cta.href==='https://www.7-zip.org/download.html'`, `cta.target==='_blank'`, `cta.rel==='noopener'`, `zipIntact===true`, `focusRestored===true`; `browser.console(level:'error')` kosong.

Nota: penutupan dengan Esc dikendali terus oleh `<dialog>` asli pelayar. `KeyboardEvent` tiruan dari automation tidak boleh dipercayai untuk menguji ini; jangan tulis kod Esc manual semata-mata untuk memuaskan ujian. Sahkan secara manual dalam pelayar dan catatkan had alat jika tidak dapat diautomasikan.

```js
(()=>{
  const keys=['z7-link','z7-title','z7-body','z7-step1','z7-step2','z7-step3','z7-cta'];

})()
```
