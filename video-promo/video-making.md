## Urutan Kerja

```
1. Rakam Skrin (Win + Alt + R) → footage/scene_03-08.mp4
         ↓
2. Rakam Voiceover (Audacity) → voiceover_pustakahadith.mp3
         ↓
3. Edit Video (Filmora) → susun scene + teks + audio
         ↓
4. Eksport & Upload → YouTube Shorts + TikTok + IG + FB
```

## Nota Teknikal

### Alat Rakaman Skrin
- Windows: **Win + Alt + R** (Xbox Game Bar — terbina dalam)
- OBS Studio: https://obsproject.com (percuma, paling bagus)

### Alat Rakaman Audio
- Audacity: https://www.audacityteam.org (percuma)
- Windows Voice Recorder (terbina dalam)

### Alat Editing Video
- Wondershare Filmora: https://filmora.wondershare.com (gunakan ini ✅)
- CapCut: https://www.capcut.com (percuma)
- DaVinci Resolve: https://www.blackmagicdesign.com (percuma)

### Resolusi
- Screen recording: 1920x1080
- YouTube Shorts: 1080x1920 (9:16)
- YouTube standard: 1920x1080 (16:9)

### Branding
- Warna teks: Putih `#FFFFFF` atau Teal `#3EC9B0`
- Font: Segoe UI Bold / Extra Bold
- Latar: Globe `latar_globe_dunia.png`
