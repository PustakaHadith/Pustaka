# Langkah 4: Eksport & Upload — Arahan Lengkap

## Eksport Video

### Eksport dari CapCut
1. Klik **Export** di bahagian atas
2. Tetapan:
   - **Resolution:** 1080p
   - **Frame rate:** 30fps
   - **Format:** MP4
   - **Quality:** High
3. Klik **Export**
4. Fail disimpan di: `D:\Pustaka Quran Hadis\Pustaka\video-promo\`

### Eksport dari DaVinci Resolve
1. Klik **Deliver** (rocket icon)
2. Tetapan:
   - **Format:** MP4
   - **Codec:** H.264
   - **Resolution:** 1920x1080 ATAU 1080x1920
   - **Frame rate:** 30fps
   - **Bitrate:** 8-10 Mbps
3. Klik **Add to Render Queue** → **Render**

### Eksport dari Adobe Premiere
1. Klik **File → Export → Media**
2. Tetapan:
   - **Format:** H.264
   - **Preset:** Match Source - High bitrate
   - **Resolution:** 1920x1080
3. Klik **Export**

### Versi 1: YouTube Shorts / Reels / TikTok (Vertikal)
- **Resolusi:** 1080 x 1920 (9:16)

## Upload ke YouTube

### 1. Log Masuk YouTube
1. Buka https://youtube.com
2. Log masuk akaun Google anda
3. Klik ikon **Create** (bulat +) di bahagian atas
4. Klik **Upload video**

### 2. Pilih Fail
1. Klik **Select files** atau drag fail video
2. Pilih `PustakaHadith_promo_youtube.mp4` atau versi Shorts

### 3. Isi Detail

**Tajuk:**
```
PustakaHadith — 62,169 Hadis dari 9 Kitab Utama | Percuma & Offline
```

**Penerangan:**
```
PustakaHadith — perpustakaan digital hadis untuk Windows.

✅ 62,169 hadis dari 9 kitab (Kutub al-Tis'ah)
✅ Teks Arab + terjemahan 4 bahasa (Melayu, Indonesia, Inggeris)
✅ Carian makna AI — taip maksud, bukan sekadar perkataan
✅ Darjat ulama & huraian ringkas
✅ Berfungsi sepenuhnya tanpa internet
✅ Percuma & open source

🔗 Muat turun: https://pustakahadith.netlify.app
💻 GitHub: https://github.com/PustakaHadith/PustakaHadith

#PustakaHadith #Hadis #KutubAlTisah #IlmuAgama #IslamicTech #OpenSource
```

**Tag:**
```
PustakaHadith, hadis, kutub al-tis'ah, bukhari, muslim, carian hadis, ilmu agama, islamic app, open source, hadith search, offline app, windows app
```

**Thumbnail:**
- Gunakan screenshot terbaik dari `screenshots/01_home.png`
- ATAU tangkap skrin dari video yang menunjukkan UI terbaik
- Saiz: 1280x720 minimum

**Kategori:** Education

### 4. Tetapan Tambahan
- **Playlist:** PustakaHadith (atau buat baru)
- **Audience:** "Not made for kids"
- **Comments:** On
- **License:** Standard YouTube License

### 5. Publish
1. Klik **Publish**
2. Tunggu processing selesai (2-5 minit)
3. Video akan live di: `https://youtube.com/watch?v=XXXXX`

## Senarai Semak Akhir

### Sebelum Publish
- [ ] Video berkualiti baik (tiada pixelated/blur)
- [ ] Audio jelas, muzik tidak terlalu kuat
- [ ] Semua teks overlay terbaca
- [ ] Sari kata timing betul
- [ ] Duration 55-60 saat
- [ ] Link dalam description berfungsi
- [ ] Thumbnail menarik

### Selepas Publish
- [ ] Semak video live dan boleh ditonton
- [ ] Semak link dalam description berfungsi
- [ ] Kongsi ke social media lain
- [ ] Reply komen pertama dengan link download
- [ ] Semak analytics selepas 24 jam
