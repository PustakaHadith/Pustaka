# Langkah 1: Rakam Skrin — Arahan Lengkap

## Pilihan Alat Rakaman

### Pilihan A: Xbox Game Bar (TERBINA DALAM — Disyorkan)
Tiada perlu install. Tekan **Win + G** untuk buka.

**Cara guna:**
1. Buka PustakaHadith dulu (`JALANKAN.bat`)
2. Tekan **Win + G** → toolbar muncul
3. Klik butang **Record** (bulat merah) atau tekan **Win + Alt + R**
4. Rakaman mula — toolbar kecil akan kelihatan di skrin
5. Tekan **Win + Alt + R** lagi untuk hentikan
6. Video disimpan di: `C:\Users\MKAW\Videos\Captures\`

**Kelebihan:**
- Tiada install diperlukan
- Rakam 1920x1080 terus
- Audio desktop turut dirakam

**Kekurangan:**
- Tiada pilihan hide cursor
- Toolbar kecil nampak di skrin (boleh crop dalam editor)

---

### Pilihan B: OBS Studio (PERCUMA — Paling Bagus)
Jika mahu kawalan penuh, install OBS Studio.

**Cara install:**
1. Buka browser → ke https://obsproject.com
2. Klik **Download Installer**
3. Buka fail yang dimuat turun → Next → Next → Install
4. Buka OBS Studio selepas install

**Cara set up:**
1. Buka OBS → klik **+** di bawah Sources → **Display Capture**
2. Pilih monitor → OK
3. Klik **Settings** → **Video** → Base: 1920x1080, Output: 1920x1080
4. Klik **Settings** → **Output** → Recording Format: MP4
5. Klik **Settings** → **Audio** → Sample Rate: 44.1kHz
6. Klik **Start Recording** untuk mula

## Persediaan Sebelum Rakaman

### 1. Bersihkan Desktop
- [ ] Tutup semua browser, folder, aplikasi lain
- [ ] Pastikan desktop bersih (wallpaper sahaja)

### 2. Matikan Notifikasi
```
Settings → System → Notifications → OFF
```
ATAU tekan **Win + A** → klik **Focus Assist** → **Alarms Only**

### 3. Sembunyikan Taskbar
```
Settings → Personalization → Taskbar → Automatically hide → ON
```

### 4. Tetapkan Resolusi
- [ ] Resolusi: 1920 x 1080 ✓ (sudah betul)
- [ ] Scale: 100% (semak di Settings → Display)

### 5. Persediaan Aplikasi
- [ ] Jalankan PustakaHadith via `JALANKAN.bat`
- [ ] Maximize window (tapi jangan fullscreen)
- [ ] Pastikan tema Aqua Glass aktif
- [ ] Pastikan home page terpapar
- [ ] Letakkan cursor di luar skrin utama

## Rakaman Scene-by-Scene

### Scene 3: Buka Aplikasi (0:10 – 0:18)
