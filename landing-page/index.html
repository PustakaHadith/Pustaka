Soalan Lazim

Jawapan ringkas

Sebelum atau selepas anda memasang.

Adakah aplikasi ini benar-benar percuma?
Ya — 100% percuma, tanpa iklan, tanpa akaun, tanpa langganan. Semua 62,169 hadis, terjemahan dan ciri dibuka sepenuhnya sejurus dipasang.
Perlukah internet selepas pemasangan?
Tidak. Semua data disimpan tempatan (SQLite). Carian AI, terjemahan, darjat dan syarah berfungsi penuh luar talian.
Berapa saiz dan keperluan sistem?
Muat turun ± 0.8–1.1 GB (data hadis penuh). Perlukan Windows 10/11 (64-bit) dan RAM minimum 4 GB. Tiada kad grafik khusus.
Kitab mana yang termasuk?
Kutub al-Tis'ah — Sahih Bukhari, Sahih Muslim, Abu Daud, Tirmizi, Nasa'i, Ibnu Majah, Musnad Ahmad, Sunan Darimi dan Muwatta' Malik. Lengkap dengan 31,322 bab.
Apa beza Store (MSIX), EXE dan ZIP?
Store — kemas kini automatik. EXE — pemasang manual. ZIP — portable, tiada pemasangan (padam folder = selesai). Semua mengandungi data yang sama.
Adakah aplikasi ini memberi hukum / fatwa?
Tidak. Ia rujukan teks sahaja — teks hadis, terjemahan, darjat dan huraian ringkas sebagaimana sumber. Untuk keputusan fiqh, rujuk ulama bertauliah.

Kenapa guna 7-Zip?

Arkib ZIP ±1 GB kadang lambat atau gagal dengan 'Extract All' Windows. 7-Zip percuma dan sumber terbuka — ekstrak lebih laju, urus laluan panjang, dan boleh terus 'Extract to folder PustakaHadith'.

  1. Muat turun dan pasang 7-Zip dari laman rasminya.
  2. Klik kanan fail ZIP → 7-Zip → Extract to folder 'PustakaHadith'.
  3. Buka folder itu dan jalankan PustakaHadith.exe. Padam folder = selesai.

Sejarah Pembikinan PustakaHadith

PustakaHadith lahir daripada penyelidikan peribadi yang dijalankan bertahun-tahun. Aplikasi desktop ini pula mula dibangunkan pada Mei 2026 dan sampai ke versi 1.0.3 di Microsoft Store pada awal Oktober 2026 — lebih kurang lima bulan dari kod pertama kepada edaran awam.

Dibina dengan Python + PyQt5 untuk antara muka desktop Windows, dengan data disimpan setempat dalam SQLite + FTS5 (indeks teks penuh) dan indeks vektor FAISS + e5-small untuk carian makna. Ringkasnya:

63,930 rekod darjatSahih / Hasan / Da'if mengikut penilaian ulama

Kualiti tidak diserahkan kepada nasib: setiap edaran melalui 381 semakan automatik dalam semak.py (15 bahagian) — kiraan hadis, konsistensi peta data, ujian susun atur skrin, ujian regresi visual, hinggalah semakan bahasa supaya dokumentasi kekal dalam Bahasa Melayu Malaysia.
